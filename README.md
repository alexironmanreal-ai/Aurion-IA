# Aurion

Personal command intelligence: a dark command deck with a reactor core, voice in and out, and a transcript that stays in the browser.

- Type an instruction or use the microphone.
- Spoken replies can be muted.
- Clock, date, and short prompts answer on the device; open questions go to the language core (`XAI_API_KEY` on the server, model `grok-4.5`).

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
